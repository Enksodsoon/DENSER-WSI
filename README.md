# DENSER-WSI

DENSER-WSI is a falsification-first research framework for testing
evidence-sensitive compression of bright-field H&E whole-slide images.

The project compares DENSER, a matched uniform same-coder control, and strong
standard-codec portfolios under the same HE-V1 acceptance contract, shared
lossless fallback, and complete-byte MC-V1 container accounting.

This repository contains public-safe code, synthetic fixtures, specifications,
tests, and aggregate reports only. It contains no clinical claim and no raw or
source-linked pathology data.

Start with [CODEX_START_HERE.md](CODEX_START_HERE.md). Reconstruction provenance
is documented in [RECONSTRUCTION_PROVENANCE.md](RECONSTRUCTION_PROVENANCE.md).
